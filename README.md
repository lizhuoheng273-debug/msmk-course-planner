# HKU MSc in Marketing 排课系统 · 2026–27

单文件交互式选课排课工具（HKU Business School **MSc in Marketing** 2026–27 学年）。

> 双击 `index.html` 即可使用，无需安装任何依赖，数据完全本地。

![screenshot](https://raw.githubusercontent.com/lizhuoheng273-debug/msmk-course-planner/main/assets/preview.png)

## 功能

- **按周视图**：完整学年 2026/9/5 – 2027/6/18，逐周查看上课安排（支持按学期筛选）
- **侧栏选课**：30 门课 / 62 个班次全部录入（含各班星期、时间、日期、教室），点击即可选/退
- **冲突自动检测**：同一时间段重叠会实时高亮标红
- **一键载入**：内置已注册的 8 门课方案（MSMK7001-E / 7004-E / 7013-A / 7015-B / 7025-C / 7002-B / 7003-D / 7005-B）
- **保存方案**：方案存入浏览器 localStorage，可保存多套对比
- **手机自适应**：窄屏自动切换为移动布局，可直接添加到手机主屏幕使用

## 快速开始

1. 下载 `index.html`（或直接访问在线版）
2. 浏览器打开，点右上「一键载入推荐」载入已注册课程
3. 也可以自由点选其他班次做 what-if 对比

## 数据来源

课程时间依据 HKU Business School 官方 *Teaching Plan 2026-2027 (MSc in Marketing)*（Appendix A），可能随学校调整而变化，以学校最新通知为准。
